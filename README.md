QR Code Component

A responsive QR code component built as a Frontend Mentor challenge.

Built with
- HTML5
- CSS3
- Flexbox
- CSS Custom Properties
- Responsive Design

What I learned

- How to translate a Figma design into HTML and CSS
- How to use CSS custom properties for design tokens
- How to use Flexbox to center and structure a component
- How to build a responsive layout without unnecessary media queries
- How to organize a simple frontend project

The challenge

The goal of this challenge was to build a QR code component that matches the provided design as closely as possible and works well across different screen sizes.
